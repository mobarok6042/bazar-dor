# বাজার দর · BazarDor

**আজকের বাজারদর, এক নজরে।**

BazarDor is a Bengali-language market price guide that helps people explore current prices for everyday products, compare prices across markets, and keep up with price changes.

## Technologies

- **Next.js 16** — App Router and server-rendered pages
- **React 19** — interactive user interfaces
- **Tailwind CSS 4** and **daisyUI 5** — responsive styling and UI components
- **HeroUI** — accessible form controls
- **Better Auth** — email/password and Google/GitHub authentication
- **MongoDB** — authentication data storage
- **react-hot-toast** — feedback for account actions
- **BazarDor API** — product, category, and market price data

## Key features

1. **Browse today’s prices** — explore product cards with Bengali names, category icons, units, current prices, and price-change indicators.
2. **Track price movements** — view the biggest price increases and decreases, with directional arrows and clear color coding.
3. **Explore categories** — browse products by category, check category product counts, and sort by price from low to high or high to low.
4. **Compare market prices** — open a product’s protected detail page to see its price change, lowest, highest, and average prices, plus market-by-market minimum and maximum prices.
5. **Manage an account** — register or sign in with email/password, Google, or GitHub; edit a profile name; and access protected product details after signing in.
